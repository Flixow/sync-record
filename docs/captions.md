# Burned-in captions

`src/shared/captions.ts` turns transcript words into caption events, an ASS file that libass renders, the boxes the captions occupy, SRT/WebVTT sidecars and the ffmpeg filter that burns them in. It is pure code: no I/O, no clock.

## Use

```ts
const style = captionStyleById("bold-box");                         // CaptionStyle | null
const events = layoutCaptions(words, canvas, style, { removed });   // CaptionLine[] on the OUTPUT timeline
const ass = toAss(events, canvas, style);                           // write to a file
const filter = captionFilter(assPath, fontsDir);                    // "ass=filename='…':fontsdir='…'"
const { srt, vtt } = captionSidecars(words, { removed, speakers: true, nameOf });
const boxes = captionBoxes(events, canvas, style);                  // Rect per event, for the editor overlay
```

- `words` are the project's `TranscriptWord`s (ms on the project timeline). `removed` is the EDL's removed ranges. Words whose midpoint lies in a removed range are dropped; the others are moved onto the output timeline with `toOutput`, so captions stay in sync with the cut video.
- `canvas` is the output size. Sizes in a style are pixels at a 1080 px short edge and scale with `min(width, height)`.
- `fontsDir` is `assets/fonts` of the shipped app. It must be present at run time: libass takes the face from there, so captions look the same on a host with no fonts installed.
- Place `captionFilter(...)` in the video chain after scaling to the final size (the ASS file's PlayRes is the canvas, so scaling afterwards would scale the captions too).
- `layoutCaptions(..., { speakers: true })` never mixes speakers in one event and sets `CaptionLine.pid`. By default an event may span a speaker change (overlapping speech is common in two-track conversations).

## Presets

| id | look | highlight | where |
| --- | --- | --- | --- |
| `clean` | Noto Sans Bold, white, outline | none | bottom |
| `bold-box` | Noto Sans Bold on a translucent black box | the spoken word is yellow | bottom |
| `karaoke-pop` | Noto Sans Bold, upper case, large, thick outline | words fill with yellow as they are spoken and stay filled | centre |
| `minimal` | Noto Sans Regular, white, thin outline | none | bottom |

Labels are English; the UI maps the ids to its own strings.

## Line breaking and timing

- At most two lines (`maxLines`), `maxCharsPerLine` per aspect (16:9, 9:16, 1:1). A word is never split. A single word longer than the line stays whole; the event shrinks its font (`\fs`) so it still fits the safe area.
- Events start and end on word boundaries. A pause over 700 ms always starts a new event; so does a speaker change when `speakers` is set. Otherwise a small dynamic programme picks the breaks: events of about 1–3 s, balanced lines, breaks after sentence and clause ends, no line ending on an article, preposition or conjunction, no one-letter word left alone.
- An event stays on screen at least 400 ms unless the next one starts sooner. Events never overlap.
- Word times are the transcript's own. Repairs, all in `prepareWords`: a word stretched over a silence (the engine spreads the first word after a pause over it) keeps its end and loses the stretched start (cap 450 ms + 110 ms per character); starts are made strictly increasing (40 ms apart at least) and a word ends no later than the next one starts; a hyphen or apostrophe piece the engine split off (`Wi` `-Fi`, `John` `'s`) is glued to its word.
- Highlight timing is written in centiseconds relative to the event start (`\t` for the word highlight, `\kf` for the karaoke fill), so on/off error is the frame period of the output plus the ASS rounding (10 ms).

## Safe area

All captions are centred in `safeArea(canvas)` (for 9:16 it keeps off the top 10 %, the right 14 %, the bottom 22 % and the left 6 %). `captionBoxes` returns, per event, a rectangle that contains everything libass draws for it (text, outline, shadow, box) and lies inside the safe area. Widths come from the bundled font's advance widths (`CAPTION_ADVANCES`, generated by `scripts/gen-caption-metrics.ts`; a unit test fails if it drifts from the font files).

## Text escaping

`escapeAssText` makes any text literal in an ASS event: `{` and `}` are escaped, a backslash is followed by a zero-width space so it can never form `\N`, `\h`, `\{` and the like, and line breaks become `\N`. `escapeFilterValue` / `captionFilter` quote a path for both levels of ffmpeg's filtergraph parsing (spaces, `' : , ; [ ] = \`).

## Checks

```
npx vitest run tests/unit/captions.test.ts tests/unit/captions-render.test.ts   # the render tests need an ffmpeg with libass
npx tsx scripts/bench-captions.ts --gates a,b,c,d --dir <scratch dir>           # prints JSON; --all-presets for gate d on every preset
```

The bench reads the product transcripts under `$TMPDIR/bench-asr3-*` and renders with libass: (a) highlight on/off timing on 60 s of English and of Polish, (b) Polish letters in every preset (cmap coverage, which font libass selected, a render with no system fonts, a second renderer), (c) 20 worst-case lines per preset inside the 9:16 safe area, estimated and on rendered frames, (d) encode time with and without captions.

The fonts are Noto Sans, SIL Open Font License 1.1: see `assets/fonts/README.md` and `assets/fonts/OFL.txt`.
